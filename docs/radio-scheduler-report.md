# Offline channel and scheduler implementation

Source is written for later MATLAB execution; no MATLAB tests or numerical acceptance results have been run here.

Receive first computes exact support bounds from the link delay and compensated FIR tails, skipping transmissions outside the window before convolution or caching. UL filtered waveforms are local to the receive call. DL filtered waveforms use an LRU cache capped at 128 MiB of complex sample storage; oversized entries are computed without caching. Repeated windows remain deterministic after eviction because taps and CFO are fixed. Optional `tx.powerNormalized=true` means the double column waveform already has physical active-sample power equal to `txPowerDbm`; this permits MATLAB copy-on-write sharing of NPRACH templates. A unit-energy PHY waveform must not set this flag. Reusable `normalizePower` and `fractionalDelay` helpers expose the active-range scaling and timestamp compensation.

`RadioChannel` normalizes each waveform using its zero-based half-open active sample ranges, applies individual path loss, the scenario's fixed UL/DL complex taps, a 65-tap windowed sinc per fractional delay, and absolute-time CFO. Full linear convolution retains both filter tails. The FIR group delay is compensated through the cached signal timestamp. UL includes twice the geometric delay plus UE synchronization error minus timing advance. DL uses physical one-way delay; receivers retain the common absolute sample clock and acquire/estimate the received timing in PHY. UL noise is added once after summing every transmission; DL receiver noise is independent. Noise is keyed by absolute millisecond and does not change when a receive window is split or revisited. Receiver windows have only waveform, rate and start sample.

`ResourceCalendar` maintains a 0.5 ms by 3.75 kHz UL lattice and independent whole-subframe DL occupancy. Each half-open policy window has separate floored RA and remaining DT quotas. Transactions check internal collisions, existing reservations, mandatory DL signals and every affected quota before committing. Release only removes entire reservations whose first sample has not started. Usage exports units and Hz seconds for both phases and directions. Grant collisions in actual waveforms share one calendar reservation.

Mandatory DL covers NPBCH at subframe 0, NPSS at 5, NSSS at 9 in even frames, and SIB1-NB at subframe 4 in the eight even frames of each 160 ms block. For schedulingInfoSIB1=0 the four blocks repeat every 640 ms and start at frame `16*(cellId mod 4)`. The repetition count and first-frame offsets follow [ETSI TS 36.213 Release 13, tables 16.4.1.3-3 and -4](https://www.etsi.org/deliver/etsi_ts/136200_136299/136213/13.13.00_60/ts_136213v131300p.pdf); the block/subframe pattern follows [ETSI TS 36.331 Release 13, section 5.2.1.2a](https://www.etsi.org/deliver/etsi_ts/136300_136399/136331/13.03.00_60/ts_136331v130300p.pdf).

`Scheduler` reserves all NPRACH occasions before traffic. Search windows start every 32 ms; their four opportunities are determined solely by the public mandatory mask, and the two actual NPDCCH repetitions always use the first two. Uplink N0 tries delays 8/16/32/64 and the four three-tone groups. N1 reserves NPDSCH plus its decoded ACK resource. RAR instead reserves Msg3 (RAR MCS index 2, three tones, one RU, two repetitions, 88 bits, 8 ms, delay 12) and has no ACK. Public reconstruction methods derive all ticks and frequencies from DCI/RAR plus public tables and return grantId zero. No booking object or true UE identity is required by a UE receiver.

The allocator tracks completion through the final UL end plus three subframes separately for each RNTI. This enforces half duplex for scheduled contexts while permitting different UE contexts to occupy disjoint UL frequencies concurrently. Initial RAR contexts sharing an RA-RNTI are conservatively serialized until a temporary C-RNTI is assigned; the engine prevents a UE with active data from starting NPRACH. Earliest-deadline request ordering and round robin context selection belong to the calling engine. Deadlines constrain the requested control/payload completion; RAR Msg3 must fit the simulation horizon and may extend beyond the RAR receive window. This is deliberate because the contention timer starts after Msg3.

Added MATLAB tests cover transactional rollback, fixed quota boundaries, release, mandatory mask, monitoring/reconstruction, RAR dependencies, deterministic split windows, common UL noise, separate receiver noise and FIR-tail retention. These tests require running after transfer to MATLAB; they are not recorded as passed.

Review correction: ACK begins at `payload.endTick + k0 - 1`, following TS 36.213 section 16.4.2's end of subframe `n+k0-1`. Because the half-open payload end is `n+1`, the earlier implementation was one millisecond early. A golden timing test fixes the resource-0 example independently of round-trip reconstruction: NPDSCH ending at tick 100 and k0=13 requires ACK ticks 112:115. The test has not been executed locally.
