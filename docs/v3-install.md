# Установка v3 на Windows

## 1. MATLAB и компоненты

Установите **MATLAB R2025b** через официальный установщик MathWorks. При выборе продуктов отметьте **MATLAB** и **LTE Toolbox**. Нужна лицензия, позволяющая использовать эти продукты; MATLAB в архив проекта не входит.

Для обычных демонстраций достаточно этих двух продуктов. **Statistics and Machine Learning Toolbox** нужен отдельно для обучения/использования соответствующих ML-моделей. Parallel Computing Toolbox нужен только для необязательных параллельных серий. Python, Simulink и GPU для описанных демонстраций не нужны.

## 2. Скачать и распаковать

На [странице v3.0.0](https://github.com/cepehao/NB-IOT/releases/tag/v3.0.0) скачайте **NB-IOT-v3.0.0.zip** из списка Assets и распакуйте. Внутри одна папка `NB-IOT-v3.0.0` со всем проектом. Репозиторий закрытый: скачивающий должен войти в GitHub под аккаунтом с доступом к нему.

В Windows распакуйте ZIP, а не запускайте файлы прямо из архива. Выберите папку с правом записи: приложение сохраняет новые результаты. В этой папке должны лежать `setupProject.m`, `startDemo.m`, `src`, `apps` и `results/nprach-calibration.mat`.

## 3. Открыть проект

Откройте MATLAB. Вверху в поле **Current Folder** выберите распакованную папку проекта. Команды вводятся в **Command Window** со знаком `>>`.

```matlab
setupProject();
startDemo;
```

Если нужно перейти в папку командой, замените путь на свой:

```matlab
cd('C:/NB-IOT-v3.0.0');
setupProject();
startDemo;
```

## Если не запускается

| Проблема | Что проверить |
|---|---|
| MATLAB не находит setupProject/startDemo | Current Folder должен содержать эти файлы; сначала распакуйте ZIP |
| Не найдены функции LTE | Выполните `ver('lte')` и `which lteNPRACH`; установите LTE Toolbox для R2025b |
| Нет калибровки | Убедитесь, что сохранён `results/nprach-calibration.mat`; не запускайте новую долгую калибровку для первой демонстрации |
| Калибровка не соответствует настройкам | Начните с startDemo и штатных параметров; не меняйте период доступа/фильтр/профиль приёмника |
| Adaptive требует модель | Это ожидаемо: независимая принятая модель в v3 отсутствует; для первого показа нужен Static |
| Не видно нижний журнал | После startDemo используйте `showRadioLog`; это большое отдельное окно существующих записей |
| Слева 10 устройств, а открыт отчёт 100 | Слева настройки нового запуска; справа сохранённый отчёт. Используйте viewDevices100 с явной сводкой |
| 5 секунд считаются дольше 5 секунд | Это модельное время; реальные вычисления заметно дольше |

Короткая проверка наличия нужных функций, без симуляции: `checkEnvironment(false);`. `checkEnvironment(true)` дополнительно выполняет физические roundtrip-проверки; для простого открытия UI это не требуется.
