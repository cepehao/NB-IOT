# Текущий снимок: v3.0.0, 16 октября 2026

Для установки и первого запуска — корневой README.md и docs/v3-install.md. Малые опыты — docs/v3-experiments.md. Что готово и что осталось — docs/v3-status.md. Полные готовые результаты — reports/README.md.

Ветка v3 содержит текущую реализацию и демонстрационный комплект. Отложенный план инженерных доработок не выполнялся; его карточки и исходный аудит сохранены в docs для последующей работы. Старый вариант 2 не возобновлять автоматически. Нагрузки >10 UE, полная калибровка, научное обучение и большие сравнения не являются частью первого запуска.

Все демонстрационные команды используют пути относительно распакованного корня. Публикация не означает достижения всех требований ТЗ или научной приёмки.
