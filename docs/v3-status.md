# Готовность v3.0.0 — 16 октября 2026

V3 — демонстрационный снимок существующего прототипа, без выполнения отложенного плана оптимизации.

| Есть и можно показать | Ещё не завершено |
|---|---|
| Физическая процедура подключения, приём данных, CRC, повторы | Полная научная проверка больших нагрузок |
| Static UI: карта, параметры, состояния, пауза/продолжение, сохранение, графики | Удобная сводка параметров открытого отчёта внутри основного UI |
| Разные типы трафика, ручные P и RA/DT | Улучшение компоновки тесного журнала |
| Два Adaptive-механизма и код обучения четырёх моделей | Независимая реальная модель, допуск внешнего Adaptive и доказательство выигрыша |
| Полные сохранённые результаты на 1 и 100 UE | Оптимизация квадратичной диагностики и памяти checkpoint |
| Короткие проверки и отдельные демонстрационные окна | Полная регрессия после всех накопленных изменений |

## Что включено из результатов

- `reports/single-ue`: полный сохранённый UI-расчёт, 1 сообщение 200 байт доставлено, 5 секунд модели, благоприятная связь. Это свежий сохранённый пример с текущего снимка.
- `reports/100-ue`: полный завершённый Static случай ID1088. Создано 100; доставлено 6; неудача 86; незавершено 8; 5 секунд модели. Это одна реализация, не среднее по серии.
- `reports/charts-single-ue`: 8 PNG графиков первого примера.
- `verification/v3/source-manifest.json`: SHA-256 вычислительного снимка.
- `verification/v3/history`: историческая проверка файлов и запись остановки большой серии. Они не являются новым прогоном.
- `verification/local/meeting-20261015/checks`: ранее выполненная короткая репетиция паузы/продолжения и живых графиков; даты в логах сохранены.

В v3 не включены незавершённый 500 UE, его контрольные точки и большие исторические каталоги. Старый файл java.opts с принудительным Java heap 32 ГБ не является входом демонстраций и не включён: проблема больших checkpoint остаётся известной.

## Граница научных выводов

Нельзя утверждать, что 6% доставки характерны для всей технологии NB-IoT или что Adaptive уже лучше Static. Исходы зависят от условий, а доказательство требует независимых повторений. Искусственные training fixtures не заменяют реальные данные. Подробный аудит всех 65 пунктов ТЗ: `docs/project-audit-2026-10-15.md`.
