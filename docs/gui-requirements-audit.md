# Повторная сверка интерфейса по §46 ТЗ

**Обновление после разбора:** местный остаток выполняется по [новому плану](superpowers/plans/2026-10-13-completion-roadmap.md). Убрано неподтверждённое приписывание владельцу решения отложить полную сверку журнала; она остаётся задачей.

Сверено с §46 исходного файла `ТЗ_NB-IoT_обновленный.pdf` (страницы 18–24), приложением MATLAB и вспомогательными функциями текущей рабочей копии. Проверки интерфейса короткие; новые тесты экспорта выполнены на графиках и одном UE. Большие UE-нагрузки не запускались.

**Итог:** новые радио-метрики подключены к итоговой сводке и карточке выбранного UE. Service outage и отдельные групповые KPI подключены к итоговой сводке из сохранённого результата; старые результаты без этих полей показывают отсутствие данных. Целевые тесты расчёта, экспорта, старого формата и сводки прошли; свежая UI/CLI проверка общей цепочки остаётся Task 6, физические значения — Tasks 7–8.

Счёт detection/miss идёт по уникальным ключам, отдельно от числа UE-попыток. | Число ключей и доля от занятых ключей; false-alarm rate — ложные ключи / все незанятые допустимые индексы в завершённых NPRACH-окнах. Capture — только перекрывающаяся пара с разными принятыми мощностями, где более сильная попытка завершила RA, а более слабая нет. | Пары, затронутые попытки, вероятность по попыткам; capture-пары / пары физического перекрытия с разными мощностями.
