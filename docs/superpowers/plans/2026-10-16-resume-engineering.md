## Если Sky снимает перекрывающее окно — восстановление 17 октября

Причина повторной остановки: сессия сознательно не активировала выбранное окно MATLAB и получала вид перекрывающего окна Codex. Простое наблюдение не запрещает вывести нужное окно на передний план. Этот обратимый шаг уже разрешён задачей; не просить владельца переключать окно вручную.

После инициализации `sky` в node_repl получить свежие окна и выбрать единственный desktop по возвращённому названию:

```javascript
const found = (await sky.list_windows()).filter(w => w.title === 'MATLAB R2025b');
if (found.length !== 1) throw new Error('Expected exactly one MATLAB desktop');
const target = await sky.get_window({id: found[0].id, app: found[0].app});
await sky.activate_window({window: target});
const observed = await sky.get_window_state({
  window: target, include_screenshot: true, include_text: true
});
nodeRepl.write(JSON.stringify({
  window: observed.window,
  documentText: observed.accessibility?.document_text,
  readyLines: String(observed.accessibility?.tree || '').split('\n')
    .filter(line => /Ready prompt|Command Window Value/.test(line))
}));
```

Просмотреть автоматически показанный screenshot и выбранный текст. Не вызывать `get_window_state(target)` без обёртки `{window:...}`; не пересохранять и не печатать base64 screenshot. Для двух демо аналогично выбрать каждое по свежему возвращённому объекту, активировать и просмотреть статус/кнопки. При обнаружении активного расчёта остановить зависимый запуск; при реальном отказе инструмента следовать его ограничениям, не обходить их.
