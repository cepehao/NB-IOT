# Установка и запуск v4.0.0

## Что потребуется один раз

Windows x64, установленный **MATLAB R2025b** и **LTE Toolbox** для этой же версии. Нужна действующая лицензия MathWorks с доступом к этим продуктам. MATLAB в архив проекта не входит. Для обычного демо другие Toolbox не нужны.

Если MATLAB ещё не установлен, откройте [MathWorks Downloads](https://www.mathworks.com/downloads/), войдите в университетский/рабочий аккаунт, выберите **R2025b** и в официальном установщике отметьте **MATLAB** и **LTE Toolbox**. Установите и активируйте их. [Официальная инструкция MathWorks](https://www.mathworks.com/help/releases/R2025b/install/ug/install-products-with-internet-connection.html).

Statistics and Machine Learning Toolbox требуется для обучения/использования соответствующих ML-моделей. Parallel Computing Toolbox нужен только для необязательных параллельных серий. Они не требуются для START.cmd и просмотра готового отчёта. Simulink, Python и GPU не нужны.

## Каждый новый выпуск

1. На [странице последнего выпуска](https://github.com/cepehao/NB-IOT/releases/latest) скачайте **NB-IOT-v4.0.0.zip** из Assets. Для закрытого репозитория войдите в аккаунт с доступом.
2. В Проводнике выберите «Извлечь всё», например в Документы. Внутри должны быть START.cmd, startNBIoT.m, src, apps, results и reports.
3. Дважды щёлкните **START.cmd** и дождитесь MATLAB. Затем нажмите «Запуск» в окне NB-IoT.

Устанавливать проект, открывать терминал, выполнять setupProject и менять системные настройки не требуется. Пользуйтесь папкой, в которую разрешено сохранять файлы; Program Files для проекта не подходит. Обновления распаковывайте отдельно.

**SAVED-100.cmd** открывает сохранённый отчёт на 100 устройств без нового расчёта. **CHECK.cmd** выводит результат проверки компонентов и ждёт нажатия клавиши.

## MATLAB уже открыт или установлен в нестандартную папку

В MATLAB выберите распакованную папку в поле **Current Folder** и выполните:

```matlab
startNBIoT
```

Только проверить установку: `startNBIoT('check')`. Открыть сохранённый отчёт: `startNBIoT('saved100')`.

Windows launcher сначала ищет стандартную установку R2025b, затем matlab.exe в PATH. Версия и компоненты повторно проверяются приложением. Для нестандартной установки достаточно команды в MATLAB. Опытный пользователь также может задать путь через переменную окружения NBIOT_MATLAB_EXE.

## Если возникла ошибка

| Сообщение/симптом | Что сделать |
|---|---|
| MATLAB не найден | Установить R2025b; если уже установлен нестандартно, открыть его и выполнить startNBIoT из папки проекта |
| Открыта другая версия | Открыть MATLAB R2025b. Другие версии для этого выпуска не проверены |
| Нет LTE Toolbox | Установить и активировать LTE Toolbox для R2025b через официальный установщик; при университетской лицензии обратиться к администратору |
| Нет калибровки/кода | Заново распаковать полный ZIP. Отдельного START.cmd недостаточно. Новую долгую калибровку считать не нужно |
| Не получается сохранить | Перенести всю папку в Документы или другое место с правом записи |
| Adaptive просит принятую модель | Начать со Static. Независимая научно принятая модель в выпуск не входит |
| Открытие заняло около минуты | Дождаться загрузки MATLAB. Не нажимать START.cmd многократно |
| 5 секунд считаются дольше | Это время модели; фактическое вычисление может быть заметно дольше |
| Слева одно устройство, в отчёте 100 | Слева параметры нового запуска. Справа в сводке показаны параметры сохранённого отчёта |

Ошибки открытия MATLAB записываются в **logs/startup-*.log**. Для диагностики достаточно последнего файла. Пароли и ключи приложению не требуются.

Установка не меняет VPN, firewall, антивирус, политику PowerShell или глобальные настройки сети.
