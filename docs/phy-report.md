# Offline PHY implementation report

Implemented source only; no MATLAB execution was performed.

`ProfileTables`: profile(kind), msg3Profile(rarIndex), ulTbs(mcs,iru,nsc), dlTbs(mcs,isf), n0Delay(index), rarDelay(index), n1Delay(index,rmax), resourceUnits(index), ulRepetitions(index), dlSubframes(index), dlRepetitions(index), decodeUlAssignment(index), encodeUlAssignment(tones), ackResource(index), nprachDurationTicks(). Profiles use format, spacingHz, numSubcarriers, modulation, nru, nulSlots, repetitions, tbs, mcs, iru, durationTicks; DL adds nsf; NPDCCH adds rmax,g,offset,ncce. FrequencyStartHz is the calendar offset from the lower edge of the180kHz band; waveform remains centered full-band baseband.

All four channels expose the offline-contracts buildTransmission/receive or detect signatures. NPUSCH/NPDSCH states contain ndi and transport decoder soft buffers. Build states contain encoder bundle states. Receivers obtain only waveform, sampleRateHz,startSample and public grant configuration. Successful Data decode requires actual Toolbox CRC==0. Control decode has hasCrc=false,crcError=NaN,status=uci and measurements.uciDetected; the caller additionally checks the decoded ACK bit. NPDCCH receives only ticks,rnti,profile,format and returns actual decoded DCI on matching CRC RNTI. Explicit physical DL ticks preserve calendar gaps.

N0 fields: format,subcarrierIndication,resourceAssignment,schedulingDelay,mcs,rv,repetitionNumber,ndi,dciRepetitions. N1 normal fields: format,order=0,schedulingDelay,resourceAssignment,mcs,repetitionNumber,ndi,ackResource,dciRepetitions. DCI rv is the one-bit offset; physical grant rv is0 or2. Standard N1 order is also packed/unpacked, using nprachRepetitions and subcarrierIndication. No grantId or UE ID is sent in DCI.

`buildMandatoryTransmission(cfg,tick)` synthesizes NPSS,NSSS,NPBCH,SIB1 using the shared mandatory mask and fixed public bootstrap bits; returns empty on an available payload tick. Payload transmissions contain NRS. `mandatoryDL` additionally accepts encoder state.

NPRACH templates are cached and trimmed to active duration. Detection is an FFT normalized correlation bank over all12 starting tones, CFO grid and sample timing offsets. Interior timing and CFO maxima receive bounded three-point parabolic refinement; the threshold metric remains the original searched-bank maximum, preserving the calibration statistic. Returned candidate fields are nInit,metric,delaySeconds,cfoHz,threshold,readyTick. Calibration is `examples/calibrateNprach.m`; it saves threshold/history only after20k fitting and fresh20k validation windows, recording acceptance and95% exact binomial limits. No calibration was run.

Practical noise estimates use pilot averaging, with UL FreqWindow23/TimeWindow1 for Data and TimeWindow3 for single-tone Control; DL NRS uses FreqWindow25/TimeWindow1. This follows the published practical-estimation examples and avoids a1x1 averaging window that would produce zero noise estimates. The eps lower bound remains only a protection for ideal noiseless numerical inputs. Short-grid estimator behavior is still a target-PC acceptance item.

Target-PC acceptance entry point: `checkEnvironment(true)` and `tests/TestPhyTables.m`, `tests/TestPhyWaveforms.m`. Numerical/API uncertainties and required fractional-delay/CFO/interference validation are listed in toolbox-compatibility.md. The UCI coherence gate has not been calibrated or numerically validated. NPUSCH timing is estimated from actual received DM-RS correlation via lteULFrameOffsetNPUSCH, restricted to available receive margins and a64-sample default search bound. The estimated timing selects the full bundle before pilot CFO compensation. The actual waveform acceptance script includes an11-sample delayed transmission. None of these numerical checks was executed offline.
