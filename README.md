# NBIoTSim — Модуль 1 и Модуль 2 интеллектуальной системы анализа коллизий NB-IoT

Julia-пакет: генератор трафика IoT-устройств (Модуль 1) и событийная
имитационная модель случайного доступа NB-IoT/NPRACH (Модуль 2). Часть
научно-исследовательского проекта «Интеллектуальная система анализа коллизий
случайного доступа в NB-IoT сетях с использованием методов машинного
обучения» (см. [docs/TZ.md](docs/TZ.md)), предназначенная для платформы
[ENGEE](https://engee.com/helpcenter/stable/ru/index.html) (Julia + опциональный
вызов функций MATLAB LTE Toolbox).

Общий пайплайн проекта:

```
Модуль 1                Модуль 2                  Модуль 3            Модуль 4
Генератор     ──▶       Имитационная      ──▶      ML-анализатор ──▶  Динамическая
трафика                 модель сети NB-IoT           коллизий            адаптация
(этот пакет)             (этот пакет)                (планируется)       (планируется)
```

## Быстрый старт

```bash
# 1. Установить зависимости (нужен Julia >= 1.9, https://julialang.org)
julia --project=. -e 'using Pkg; Pkg.instantiate()'

# 2. Прогнать тесты — включая сверку событийной симуляции с аналитическими
#    формулами теории вероятностей (ожидается "2174 passed, 0 failed")
julia --project=. -e 'using Pkg; Pkg.test()'

# 3. Посмотреть демонстрацию (генерирует PNG-графики в examples/)
julia --project=examples examples/run_full_demo.jl
```

Минимальный пример использования — в [docs/ARCHITECTURE.md, раздел 9](docs/ARCHITECTURE.md#9-как-запустить).

## Что уже сделано / что дальше

- ✅ **Модуль 1** — генератор трафика (периодический, всплеск, аварийный
  массовый доступ, нисходящий) на основе моделей 3GPP TR 37.868.
- ✅ **Модуль 2** — событийная модель NPRACH: выбор преамбул, коллизии,
  backoff, повторные попытки, абстрактная DT-фаза. Математически сверена с
  аналитическими формулами (см. `test/test_collision_analytics.jl`).
- ⏳ **Модуль 3** (ML-анализатор) и **Модуль 4** (динамическая адаптация) —
  не реализованы в этом пакете. `NPRACHConfig` уже названа полями,
  совместимыми с MATLAB-структурой `chs` (`lteNPRACH`), а `src/MatlabBridge.jl`
  фиксирует контракт для будущей интеграции физического уровня.
