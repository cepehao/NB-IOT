# NB-IoT v4.0.0

Симулятор NB-IoT с графическим интерфейсом: подключение устройств, передача сообщений, повторы, радиодиагностика и сохранение результатов. Выпуск для **Windows x64 + MATLAB R2025b + LTE Toolbox**.

## Скачать и запустить

1. На [странице последнего выпуска](https://github.com/cepehao/NB-IOT/releases/latest) скачайте **NB-IOT-v4.0.0.zip** из **Assets**. Репозиторий закрытый: нужен GitHub-аккаунт с доступом.
2. Полностью распакуйте ZIP, например в папку «Документы». Устанавливать проект отдельно не нужно.
3. Дважды щёлкните **START.cmd**. Откроется MATLAB и готовое окно демо. При первом запуске MATLAB может открываться около минуты.
4. В окне нажмите **«Запуск»**. Начальные настройки: одно устройство, одно сообщение 200 байт, благоприятная связь, 5 секунд модельного времени. Ожидаемый результат: доставлено одно сообщение, 1600 полезных бит.

**Обычному пользователю не нужны Git, Python, PowerShell 7, Simulink, GPU и ручная настройка путей.** MATLAB и LTE Toolbox устанавливаются отдельно по лицензии MathWorks. [Установка и решение проблем](docs/v4-install.md).

| Файл | Что делает |
|---|---|
| **START.cmd** | Открывает демо с одним устройством; расчёт начинается после кнопки «Запуск» |
| **SAVED-100.cmd** | Открывает сохранённый отчёт на 100 устройств без нового расчёта |
| **CHECK.cmd** | Проверяет MATLAB, LTE Toolbox, калибровку и возможность сохранения; симуляцию не запускает |

Если MATLAB уже открыт, выберите папку распакованного проекта в **Current Folder** и в **Command Window** выполните:

```matlab
startNBIoT
```

Готовый отчёт: `startNBIoT('saved100')`. Проверка установки: `startNBIoT('check')`. Старые команды `setupProject; startDemo;`, `viewSaved100;`, `viewDevices100;` и `showRadioLog;` также сохранены.

## Что можно делать

- Настраивать сеть, канал, трафик и контроллер; запускать, ставить на паузу, продолжать и останавливать короткий расчёт.
- Смотреть карту, состояния устройств, графики, показатели и журнал радиособытий. Кнопки пояснений объясняют показатели.
- Сохранять результат в MAT/CSV и экспортировать графики в PNG. Для нового запуска выбирайте отдельную папку сохранения.
- Открывать готовые отчёты и видеть их параметры, итоговые показатели, таблицу и график. Настройки слева относятся к **новому** расчёту; параметры открытого отчёта показаны отдельно.
- Использовать программные механизмы подготовки данных, обучения, проверки моделей и переноса экспериментов. Для обучения нужна **Statistics and Machine Learning Toolbox**; для обычного демо она не требуется.

Местный интерактивный режим ограничен **10 устройствами**. Пять секунд в настройках — время внутри модели; расчёт может занимать дольше. Тяжёлые серии автоматически не запускаются.

## Готовые результаты

В `reports` включены полные сохранённые примеры на 1 и 100 устройств и восемь PNG-графиков. Это исторические проверенные результаты из v3, сохранённые с исходными датами и контрольными суммами.

В примере 100 устройств: 100 сообщений, из них 6 доставлено, 86 неудачных, 8 незавершённых за 5 секунд модели. Это один конкретный сценарий; он не является общей оценкой NB-IoT или доказательством преимущества Adaptive. [Состав результатов](reports/README.md).

## Готовность выпуска

V4 объединяет инженерные доработки после v3: диагностику, сохранение/восстановление, подготовку данных, проверки моделей, интерфейс и переносимый внешний маршрут. Это рабочий выпуск текущего прототипа. **Полная научная приёмка и выполнение всего ТЗ остаются открытыми.** Независимая принятая ML-модель в комплект не входит; внешний Adaptive без допуска заблокирован.

Что проверено именно для v4 — [результаты проверок](verification/v4/validation.json). Ограничения и оставшиеся условия — [статус v4](docs/v4-status.md). Изменения — [описание выпуска](RELEASE.md). Подробное руководство — [GUI guide](docs/gui-guide.md), внешние эксперименты — [runbook](docs/external-runbook.md).

## Если не открылось

Сначала запустите **CHECK.cmd**. Нужен именно **MATLAB R2025b** с активным **LTE Toolbox**. Не запускайте файлы внутри ZIP и не переносите отдельно один START.cmd: нужна вся папка. Ошибки открытия MATLAB сохраняются в `logs/startup-*.log`. [Подробная инструкция](docs/v4-install.md).

Для обновления распакуйте новый выпуск в отдельную папку и перенесите только свои результаты. Смешивать файлы разных выпусков не нужно.
