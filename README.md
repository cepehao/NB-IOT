# NB-IoT — v3.0.0

Работающий исследовательский прототип для **Windows + MATLAB R2025b + LTE Toolbox**. Есть интерфейс, физическая процедура подключения и передачи сообщений, графики, сохранение и готовые результаты. Полная научная приёмка и доказательство пользы Adaptive ещё не завершены.

**Скачать:** [NB-IOT-v3.0.0.zip](https://github.com/cepehao/NB-IOT/releases/download/v3.0.0/NB-IOT-v3.0.0.zip). Репозиторий закрытый: нужен GitHub-аккаунт с доступом. MATLAB устанавливается отдельно.

## Установить и запустить

1. Установите MATLAB **R2025b** и **LTE Toolbox**. [Подробная инструкция](docs/v3-install.md).
2. Скачайте и **распакуйте** ZIP. В MATLAB выберите распакованную папку `NB-IOT-v3.0.0` в поле **Current Folder**.
3. В **Command Window** со знаком `>>` выполните:

```matlab
setupProject();
startDemo;
```

Откроется окно с готовыми настройками: **1 устройство, сообщение 200 байт, 5 секунд модельного времени, хорошие условия связи**. Нажмите **«Запуск»**. В итоговой сводке ожидается **создано 1, доставлено 1**. Пять секунд модели считаются дольше пяти реальных секунд; локальный предел расчёта — 300 секунд.

Если возникла ошибка, начните с [раздела установки и диагностики](docs/v3-install.md), а не с изменения калибровки.

## Готовые результаты — без нового расчёта

```matlab
viewSaved100;    % график и таблица сохранённого случая на 100 устройствах
viewDevices100;  % расстояния, условия и исход каждого устройства
```

В этом случае за 5 секунд создано 100 сообщений: **6 доставлено, 86 завершились неудачей, 8 остались незавершёнными**. Это одна конкретная реализация, не общая оценка всей технологии NB-IoT.

Полные MAT/CSV и контрольные суммы лежат в [reports](reports/README.md). Там же сохранён малый успешный случай и 8 PNG графиков. Число устройств слева в основном UI относится к настройкам следующего запуска; параметры открытого архива оно не показывает. Таблица viewDevices100 подписана отдельно.

## Что попробовать самостоятельно

[Короткие эксперименты по шагам](docs/v3-experiments.md): одно сообщение, периодические сообщения раз в секунду, изменение вероятности попытки P и распределения RA/DT. Все примеры — на одном устройстве, без обучения и больших нагрузок.

После startDemo можно открыть журнал большим окном:

```matlab
showRadioLog;
```

В UI есть «Пауза», «Продолжить», «Сохранить» и экспорт 8 графиков PNG. Для сравнения временных рядов открывайте `*_kpi.csv`; `*_summary.csv` содержит итоговые числа и этой кнопкой не открывается.

## Что входит и что пока не готово

В комплекте весь текущий код src/apps/configs/examples/experiments/tests, принятая калибровка `results/nprach-calibration.mat`, два полных готовых результата, графики, исходное ТЗ и технические отчёты. Не нужны Python, Simulink или GPU для описанных демонстраций.

**Static работает в описанных примерах.** Два Adaptive-механизма и код четырёх ML-моделей включены, но независимой принятой модели нет; обычный внешний Adaptive запуск пока заблокирован. Для ML отдельно нужен Statistics and Machine Learning Toolbox. Список ограничений и TODO: [статус v3](docs/v3-status.md). [Полный аудит по ТЗ](docs/project-audit-2026-10-15.md).

Большие серии, полное обучение и вся папка tests автоматически не запускаются. Не вызывайте runStaticSweep/runLoadPilot без параметров: их настройки по умолчанию включают тяжёлые нагрузки. Нужны отдельный бюджет и завершение инженерных доработок. Для кратких технических проверок — verification/local/runBoundedChecks.ps1 с конкретными файлами, 300 секунд на файл / 900 на набор.
