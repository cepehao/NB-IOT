# Свидетельства проверок

Для **этого выпуска v3** используйте `v3/source-manifest.json` и `v3/release-check.json`. Итоговая проверка ZIP после распаковки публикуется отдельным файлом `v3-validation.json` в Assets выпуска GitHub вместе с ZIP и SHA256SUMS.txt.

`history/v2` содержит неизменённые свидетельства прежней версии (полный набор тестов, манифесты, суммы). Они не означают, что полная регрессия выполнена для v3. Остальные датированные отчёты сохранены как техническая история; их даты и ограничения остаются в силе.

`local/meeting-20261015/checks` — репетиция существующего UI, выполненная до упаковки. Свежие короткие проверки именно исходной папки v3 записываются в `v3/checks`. Набор специально ограничен; весь tests/ автоматически не выполняется.

Для запуска симулятора из этой папки нужны лишь соответствующие модули/fixtures; полноценные исторические гигабайтные серии не являются обязательным входом UI и не включены. Обязательная калибровка лежит в results/nprach-calibration.mat. Все вычислительные файлы совпадают с рабочим снимком, см. v3/source-manifest.json.
