# Проверки поставки v2

Эта папка содержит свидетельства, а не обязательные входные данные симулятора. Для запуска нужны код, конфигурация и results/nprach-calibration.mat; команды приведены в корневом README.

## Свежая проверка точной папки публикации

- v2-validation.json — число и статус тестов, результат одиночной доставки, три малых независимых случая, проверка всех трёх MAT/CSV-пакетов и повторный resume.
- full-suite.mat — результаты полного набора MATLAB-тестов.
- source-manifest.json — относительные пути и SHA-256 всех 115 MATLAB-файлов поставки. Её совокупный SHA также указан в v2-validation.json. Исходный принятый кандидат имел SHA d67fc6cac7ac9f27852177b4a1baee2c70f98b3bfe5de2fa3507397d93d2ff46; при упаковке изменены только два пути необязательного GPU-бенчмарка. Остальные 114 файлов совпадают побайтово.
- package-files.sha256 — пути и SHA-256 файлов комплекта, кроме самого списка. Сгенерированные выходные results в него не включены.
- fixtures/r1-weak-parameters.mat — входной физический сигнал для отдельного benchmarkNprachGpu. Его выходные результаты записываются в results/gpu-fft. Проверка численного совпадения CPU/GPU выполняется отдельно от штатного CPU-симулятора.

Проверка выполняется на том же Windows x64 ПК с MATLAB R2025b/LTE Toolbox, в отдельной папке публикации. Это не подтверждает другие ОС или полную научную приёмку. Фактические числа и длительности смотрите в v2-validation.json.

## Прежние измерения

В reports лежат отчёты этапов O2–O5, кэша профилей, радиопроверок R1–R3, GPU и выбранных диагностик. Их даты, ограничения и ссылки на локальные материалы сохранены. Сырые выборки длительных экспериментов не нужны для первого запуска и не включены в этот небольшой выпуск. Команды новых экспериментов доступны в experiments; полные серии автоматически не запускаются.

Границы текущей готовности: [карта приёмки](../docs/acceptance-coverage.md) и [отчёт проверок](../docs/performance-report.md).
