# NB-IoT v3 — демонстрационный выпуск

Это снимок работающего прототипа для Windows / MATLAB R2025b / LTE Toolbox.
Начать с README.md. Проверенные демонстрации: startDemo, viewSaved100,
viewDevices100, showRadioLog (после startDemo).

Научное ядро сохранено побайтово относительно рабочего снимка; SHA-256 —
verification/v3/source-manifest.json. Это не полностью завершённый проект:
ограничения и TODO перечислены в docs/v3-status.md и аудите.

Не запускать большие нагрузки/полные серии/обучение автоматически.
Местные проверки: ≤10 UE, ≤300 секунд на файл/случай, ≤900 секунд на набор
через verification/local/runBoundedChecks.ps1. Выбирать конкретные тесты.
Старый вариант 2 остановлен владельцем; его сценарии — история, не команда
возобновить серию. Не менять исторические результаты, hashes или ID ради
прохождения проверки; не удалять main/v2/предыдущие теги и выпуски.
