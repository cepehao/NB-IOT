# Готовые результаты в v4

Исторические примеры из v3 включены в v4 побайтово с исходными датами и контрольными суммами. Для просмотра без пересчёта откройте SAVED-100.cmd в корне проекта.

| Каталог | Устройств | Создано сообщений | Доставлено | Неудача | Незавершено | Время модели |
|---|---:|---:|---:|---:|---:|---|
| single-ue | 1 | 1 | 1 | 0 | 0 | 5 с |
| 100-ue | 100 | 100 | 6 | 86 | 8 | 5 с |

В обоих случаях размер сообщения 200 байт. Условия двух случаев различаются: single-ue — специально благоприятный малый пример, 100-ue — распределённые устройства в выбранном сценарии. Это не контролируемое сравнение исключительно по числу устройств.

В каждом каталоге есть полный MAT с переменной `result`, таблицы CSV и `case-complete.json` с контрольными суммами. Файлы скопированы побайтово из завершённых расчётов. Отсутствие незавершённых сообщений не требуется для статуса completed: он относится к окончанию горизонта наблюдения.

Для просмотра без нового расчёта выполните из корня проекта:

```matlab
setupProject();
viewSaved100;    % таблица по времени и график
viewDevices100;  % условия и исход каждого из 100 устройств
```

Полный результат при необходимости:

```matlab
saved = load(fullfile(pwd,'reports','100-ue','static-v1_n100_r1088.mat'),'result');
disp(saved.result.kpiSummary);
```

Это чтение сохранённого MAT, а не новый запуск. Для обычного просмотра достаточно CSV; MAT заметно больше.
